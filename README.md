# ua-values

Тест цінностей на одному вимірі, у стилі IDRlabs: сторінка з запитаннями,
липка панель із прогресом і сторінка результату з вісю та підписом діапазону.

## Де редагувати запитання

Усе живе в `src/questions.ts` — більше ніде нічого міняти не треба:

- `axis.low` / `axis.high` — полюси осі (від'ємні ваги тягнуть до `low`, додатні — до `high`);
- `scale` — стандартні варіанти відповіді: `label` + `weight`;
- `questions` — самі запитання; якщо не задати `answers`, беруться варіанти зі `scale`
  (тобто можна перевизначити шкалу окремо для конкретного запитання);
- `bands` — підписи результатів: `min` — відсоток «на бік `axis.high»», `title`, `description`;
- `power` — друга шкала на сторінці результату: `label`, `hint` і власні `bands`. Потужність = `|W1| + |W2| + ... + |Wn|` — сума модулів ваг обраних відповідей без нормалізації. Смужка й `bands` орієнтуються на відсоток цієї суми від теоретичного максимуму.

Логіка підрахунку — `src/scoring.ts`, розмітка — `src/ValuesTest.tsx` + `src/ValuesTest.css`.
